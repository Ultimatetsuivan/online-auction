# Удиртгал

## 1. Сэдэв сонгосон үндэслэл, судалгааны асуудлыг тодорхойлох

Сүүлийн хорин жилд цахим худалдааны салбар дэлхий нийтэд ихээхэн хурдтай хөгжиж, өргөн хүрээний хэрэглэгчид интернетийн орчинд бараа бүтээгдэхүүн худалдан авах, борлуулах болсон. Дотоодын статистикийн мэдээгээр Монгол улсын интернет хэрэглэгчдийн 60 гаруй хувь нь сар бүр аль нэг цахим худалдааны платформоор үйлчлүүлж байна. Гэвч ихэнх дотоодын платформ нь нэг үнийн (fixed price) худалдааг гол хэлбэрээрээ авч үздэг бөгөөд хэрэглэгч өөрсдөө үнэ тогтоох, өрсөлдүүлэх боломжтой *дуудлага худалдаа* (auction) маягийн систем нь хязгаарлагдмал хэвээр байна.

Хэрэглэгчдэд хялбар, шуурхай худалдаа хийх боломжийг олгох, цагийн хуваарьт суурилсан автомат худалдааг цахим хэлбэрээр зохион байгуулах нь уламжлалт, нэгэн хэвийн худалдааны системүүдээс илүү үр дүнтэй, хүртээмжтэй, уян хатан шийдэл болох нь ажиглагдаж байна. Олон нийтийн хэрэгцээ, техник технологийн хөгжил, хэрэглэгчдийн хандлага өөрчлөгдөж буй энэ үед цахим дуудлага худалдааны систем нь орчин үеийн шаардлагад нийцсэн, байгальд ээлтэй, хаягдал багатай, илүү зохион байгуулалттай худалдааны арга хэлбэр юм.

Үүний зэрэгцээ Японы Mercari, Yahoo!Auctions, олон улсын eBay, Зүүн Өмнөд Азийн Shopee Live Auction зэрэг өсөн дэвжих платформын туршлага нь дуудлага худалдаанд суурилсан загвар нь:

* Хуучин эд зүйлсийн дахин эргэлтийг бий болгож, экологийн ачааллыг бууруулдаг;
* Үнэ тогтоолтыг зах зээлийн зарчмаар бодит цагт явуулдаг;
* Худалдаачин ба худалдан авагчдын хооронд итгэлцлийн систем (rating, reviews) бий болгодог;
* Мобайл-түлхүү (mobile-first) хэрэглэгчийн нөхцөлд тохиромжтой;

гэдгийг харуулсан байдаг. Эдгээр зарчмыг Монголын зах зээлд тохируулан буулгасан, Монгол хэлний бүрэн дэмжлэгтэй, төгрөг валюттай, дотоодын төлбөрийн систем (QPay) болон иргэний баталгаажуулалттай (eMongolia) холбогдох боломжтой цогц системийг хөгжүүлэх шаардлага бий болсон.

Иймд **судалгааны үндсэн асуудал** нь: *Хэрхэн Монголын зах зээлд тохирсон, бодит цагийн (real-time), олон платформ дээр (web + iOS + Android) ажилладаг, аюулгүй, найдвартай онлайн дуудлага худалдааны системийг хөгжүүлэх вэ?* — гэдэгт оршино.

## 2. Зорилго

Цахим дуудлага худалдааны системийг хөгжүүлснээр худалдагч болон худалдан авагч нарт хэрэглэхэд хялбар, найдвартай, хүртээмжтэй орчинг бүрдүүлэх боломжтой болно. Энэхүү систем нь худалдан авагчид болон борлуулагчдыг шууд холбож, аюулгүй, ил тод дуудлага худалдааны үйл ажиллагааг дэмжих зорилготой бөгөөд ингэснээр худалдааны процессыг илүү үр дүнтэй, найдвартай болгоно.

Мөн цахим дуудлага худалдааны систем нь хуучин бараа, эд зүйлсийн дахин ашиглалт, шилжүүлэн борлуулалтыг дэмжснээр хог хаягдлын хэмжээ буурахад өндөр хувь нэмэр оруулдаг. Ийм байдлаар хуучин эд зүйлс дахин хэрэглэгдэх боломжтой болж, хог хаягдлын ачааллыг багасгах төдийгүй байгаль орчны бохирдлыг бууруулах, нөөц баялгийг үр ашигтай ашиглахад чухал үүрэг гүйцэтгэнэ. Тиймээс цахим дуудлага худалдааны систем нь орчин үеийн нийгэмд эдийн засаг, байгаль орчны тогтвортой хөгжилд дэмжлэг үзүүлэх чухал хэрэгсэл болж байгаа юм.

## 3. Зорилт

Дээрх зорилгод хүрэхийн тулд дараах зорилтуудыг тавьсан:

1. **Бодит цагийн харилцаа**: Socket.IO технологи ашиглан үнийн өөрчлөлт, дуудлага худалдааны үлдсэн хугацаа, шинэ оролцогчдын тухай мэдээллийг хэрэглэгчдэд саатал багатай дамжуулах.
2. **Төлбөрийн систем**: Монголын зах зээлд хамгийн өргөн хэрэглэгддэг QPay системтэй холбогдох, ирээдүйд карт болон банкны шилжүүлгийг дэмжих боломжтой архитектур зохион байгуулах.
3. **Олон төрлийн нэвтрэлт**: Хэрэглэгчийн нэвтрэх, бүртгүүлэх хэсгийг Google OAuth, утасны дугаараар баталгаажуулалт (Firebase Phone Auth), и-мэйл нэвтрэлттэй интеграцичилах.
4. **Автомат дуудлага худалдаа**: Дуудлага худалдааны хугацаа дуусахад ялагчийг автоматаар тогтоох, мөнгийг шилжүүлэх, мэдэгдэл явуулах үйл явцыг хүний оролцоогүйгээр гүйцэтгэх.
5. **Найдвартай хадгалалт**: MongoDB Atlas үүлэн өгөгдлийн санд хэрэглэгч, бараа, дуудлагын мэдээллийг хадгалж, индексжүүлэлт, репликаци бэлдсэн архитектур ашиглах.
6. **Аюулгүй байдал, гүйцэтгэл**: JWT токены аутентификаци, bcrypt нууц үгийн хэшлэлт, role-based authorization, rate limiting, CORS бодлогуудыг хэрэгжүүлэх. Хариу өгөх дундаж хугацааг 500 мс-ээс хэтрэхгүй байх төлөвлөгөөтэй ажиллах.
7. **Тестийн бүрхэвч**: Backend-ийн логикийг Jest юнит тестээр, API-уудыг Insomnia/Postman ашиглан end-to-end байдлаар, харин мобайл/веб клиентийг Expo Go болон бодит төхөөрөмж дээр функциональ тестээр шалгах.

## 4. Судалгааны объект, субъект, аргачлал

**Судалгааны объект**: Онлайн дуудлага худалдааны цогц системийн архитектур, түүний бүрэлдэхүүн (backend API, веб клиент, мобайл клиент, өгөгдлийн сан).

**Судалгааны субъект**: Бодит цагийн (real-time) дуудлага худалдааны логик, олон платформ хооронд төлвийг ижил байлгах механизм, Монголын зах зээлд тохирсон бизнес шаардлагууд (QPay, eMongolia, Монгол хэл, төгрөг).

**Аргачлал**: Судалгаандаа дараах аргачлалуудыг хослуулан ашигласан:

* *Уран зохиолын тойм*: Дуудлага худалдааны эдийн засгийн онол, аукшины математик загвар, цахим худалдааны архитектурын тухай эх сурвалжуудыг судалсан.
* *Харьцуулсан судалгаа*: Yahoo! Auctions, Mercari, eBay, Shopee Live Auction, мөн Монголын Shoppy.mn, Unegui.mn зэрэг ижил төстэй платформын онцлогийг шинжилсэн.
* *Системийн загварчлал*: UML диаграмууд (use case, class, sequence, state, activity), өгөгдлийн санд ERD ашиглан системийн бүтцийг тодорхойлсон.
* *Хөгжүүлэлт*: Agile arrange-н зарчмаар модулийн дарааллаар (sprint-маягтайгаар) хөгжүүлж, GitHub-аар хувилбарын удирдлага хийсэн.
* *Тест*: Юнит тест (Jest), интеграц тест, API тест (Insomnia), мобайл функциональ тест.

## 5. Судалгааны хамрах хүрээ

Энэхүү систем нь Монгол орны аль ч бүс нутагт оршин суугаа хүн бүрд тохиромжтой. Ялангуяа өөрт хэрэггүй болсон бараа, эд зүйлсийг бусдад худалдаалах сонирхолтой хувь хүн, жижиг дунд бизнес эрхлэгчид, мөн хямд үнээр шаардлагатай барааг худалдан авах хүсэлтэй хэрэглэгчид гол хэрэглэгчид болно. Систем нь олон нийтийн түвшинд өргөн хүрээнд ашиглагдах боломжтой бөгөөд цахим худалдааны хүртээмжийг нэмэгдүүлнэ.

Системийн **техникийн хамрах хүрээ** нь дараах байдалтай:

* **Backend**: Node.js + Express + MongoDB, Socket.IO, JWT, Firebase Admin SDK
* **Веб**: React.js + Vite + Tailwind CSS + Socket.io-client
* **Мобайл**: React Native + Expo + Expo Router
* **Үүлэн үйлчилгээ**: MongoDB Atlas (өгөгдөл), Cloudinary (зураг), Firebase (мэдэгдэл/баталгаажуулалт), Google OAuth

Системийн **функциональ хамрах хүрээ**: Хэрэглэгч бүртгүүлэх/нэвтрэх, бараа байршуулах (хамгийн ихдээ 20 зураг), категорийн ангилал, AI-аар санал болгох ангилал, дуудлага худалдаа эхлүүлэх (төлөвлөсөн эсвэл нэн даруй), үнэ санал болгох, watchlist, мэдэгдэл, гүйлгээний түүх, үнэлгээ/сэтгэгдэл, ялсан/ялагдсан жагсаалт, админы удирдлага.

Системд **багтахгүй** зүйлс: Шууд видео дамжуулалт (live streaming), олон улсын төлбөрийн карт (Stripe/PayPal), биет хүргэлтийн логистик удирдлага. Эдгээрийг ирээдүйн хөгжүүлэлтэд оруулна.

## 6. Шинэлэг тал ба ач холбогдол

Дотоодын ижил төстэй платформуудаас энэ систем нь дараах шинэлэг талтай:

1. **Цогц платформын стратеги**: Дотоодод нэг өсөн дэвжих хувилбар нь хүснэгтэн зар (classifieds, ж.нь Unegui.mn) хэлбэртэй боловч жинхэнэ "live auction" туршлага нь бараг алга. Энэ систем нь Mercari-Yahoo маягийн live auction-ийг дотоодын зах зээлд анх удаа авчирч байна.
2. **Cross-platform parity**: Веб ба мобайл клиент 100% функциональ ижил тэгш. Хэрэглэгч дуудлага худалдааг гар утсан дээрээ эхлүүлээд компьютер дээрээс үргэлжлүүлэх боломжтой.
3. **AI-аар санал болгох ангилал**: Барааны нэр, тайлбар, зураг дээр үндэслэн 66 ангилалаас тохирох категорийг автоматаар санал болгоно. Энэ нь буруу ангилсны улмаас хайлтанд тусдаггүй болохоос сэргийлдэг.
4. **Trust score систем**: Хэрэглэгчийн нэр хүндийг trustScore (0-100) хэлбэрээр хэмжиж, completedDeals, cancelledBids, identityVerified, eMongoliaVerified гэх мэт хүчин зүйлийн нийлбэрээр тооцоолно. Ингэснээр хууран мэхлэлтийн эрсдлийг бууруулна.
5. **Дотоодын баталгаажуулалт**: eMongolia ID ашиглан иргэний баталгаажуулалт хийгдсэн хэрэглэгч "Verified" гэсэн тэмдэгтэй болдог. Энэ нь дотоодын зах зээлд найдвартай байдлыг нэмэгдүүлдэг.

## 7. Ач холбогдол

Онлайн дуудлага худалдааны систем нь хувь хүн болон жижиг дунд бизнес эрхлэгчдэд дараах хэд хэдэн ач холбогдолтой:

* Түрээсийн зардал өндөртэй уламжлалт худалдааны хэлбэрээс татгалзаж, зардлыг бууруулах боломжийг олгоно.
* Өөрт хэрэггүй болсон бараа, эд зүйлсээ бусдад цахим орчинд хялбар аргаар борлуулах боломжтой болсноор эдийн засгийн эргэлтэд оруулах нөхцөл бүрдэнэ.
* Хуучин эд зүйлсийг дахин ашиглуулах, дахин хэрэглэх боломжийг бүрдүүлснээр хог хаягдлыг бууруулахад өндөр хувь нэмэр оруулна. Энэ нь байгаль орчны ачааллыг бууруулж, тогтвортой хөгжилд чиглэсэн бодит алхам юм.
* Хэрэглэгчдийн цаг хугацаа, зардлыг хэмнэж, илүү хурдан шуурхай аргаар шаардлагатай бараагаа олох боломжийг нэмэгдүүлнэ.
* Бизнес эрхлэгчдэд илүү өргөн хүрээний зах зээлд хүрэх, хэрэглэгчдийн мэдээлэлд үндэслэн борлуулалтаа оновчтой болгох боломжийг олгоно.

## 8. Системийн бүтэц, хамрах хүрээ

Энэхүү төгсөлтийн ажилд онлайн дуудлага худалдааны бүрэн цогц систем (full-stack system) хөгжүүлсэн бөгөөд дараах 3 үндсэн бүрэлдэхүүн хэсэг багтана:

* **Backend API систем** — Node.js, Express.js, MongoDB ашиглан хөгжүүлсэн RESTful API сервер. Хэрэглэгч, бараа, дуудлага худалдаа, гүйлгээний удирдлага, бодит цагийн Socket.io холболт, аюулгүй байдлын функцүүд зэргийг агуулна.
* **Веб аппликейшн** — React.js болон Vite ашиглан хөгжүүлсэн веб интерфэйс. Админы удирдлагын хэсэг, дэлгэрэнгүй дансны тохиргоо, бүрэн функционал бүхий дуудлага худалдааны интерфэйсийг багтаана.
* **Мобайл аппликейшн** — React Native болон Expo framework ашиглан хөгжүүлсэн, iOS болон Android төхөөрөмж дээр ажилладаг cross-platform мобайл програм. Гар утсаар дуудлага худалдаанд оролцох, бараа нэмэх, хайлт хийх боломжийг бүрдүүлнэ.

Энэхүү системийн онцлог нь multi-platform (олон төхөөрөмж дээр ажиллах) шинж чанартай байна. Хэрэглэгч өөрт тохирсон платформ (веб эсвэл мобайл) дээр системийг ашиглах бүрэн боломжтой.

## 9. Дипломын ажлын бүтэц

Энэхүү дипломын ажил нь дөрвөн үндсэн бүлэг ба дүгнэлтээс бүрдэнэ:

* **Бүлэг 1: Онолын хэсэг.** Дуудлага худалдааны үндсэн ойлголт, төрлүүд, түүхэн хөгжил, эдийн засгийн онол, ашигласан технологийн стек, дэлхий нийтийн болон дотоодын ижил төстэй платформын харьцуулсан судалгаа.
* **Бүлэг 2: Системийн шинжилгээ ба загварчлал.** Хэрэглэгчдийн ангилал, функциональ ба функциональ бус шаардлага, 3-tier архитектур, ERD, класс/дараалал/төлөв/үйл ажиллагааны диаграмууд.
* **Бүлэг 3: Системийн хөгжүүлэлт.** Backend, веб, мобайлын технологийн сонголтын үндэслэл, модулиудын хэрэгжүүлэлт, RESTful API endpoint-ын зохион байгуулалт, бодит цагийн Socket.IO event-үүд, аюулгүй байдлын механизм.
* **Бүлэг 4: Туршилт, үр дүн.** API endpoint-ын тестийн үр дүн, юнит тест (Jest), интеграц тест, мобайлын функциональ тест, гүйцэтгэлийн хэмжилт.
* **Дүгнэлт**: Үндсэн үр дүн, давуу талууд, хязгаарлалт, ирээдүйд хийж болох хөгжүүлэлтүүд.

## 10. Гарах үр дүн

* Веб болон мобайл платформ дээр ажилладаг бүрэн цогц дуудлага худалдааны систем бий болно.
* Дуудлага худалдааны үйл явцыг бүрэн автоматжуулсан цахим систем бий болно.
* Худалдан авагч, борлуулагчдын хоорондын харилцааг хялбаршуулсан орчин бүрдэнэ.
* Бодит цагийн мэдээлэл дамжуулдаг, ил тод, найдвартай систем хөгжүүлэгдэнэ.
* iOS болон Android төхөөрөмж дээр ажилладаг мобайл аппликейшн хөгжүүлэгдэнэ.
* Ашиглахад хялбар хэрэглэгчийн интерфейстэй платформ бий болно.
* Системийн аюулгүй байдал, өгөгдлийн хамгаалалт сайжирна.
* Дуудлага худалдааны зах зээлийн үйл ажиллагааг дэмжих технологийн шийдэл бий болно.
