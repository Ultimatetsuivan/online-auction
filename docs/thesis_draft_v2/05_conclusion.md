# Дүгнэлт

Энэхүү төслийн хүрээнд бид онлайн дуудлага худалдааны цогц системийг амжилттай хөгжүүлсэн. Систем нь веб апликейшн, мобайл апликейшн, backend сервер гэсэн 3 үндсэн хэсгээс бүрдэж, бүгд хамтран ажиллаж, хэрэглэгчдэд бүрэн функциональ, найдвартай, хүртээмжтэй дуудлага худалдааны үйлчилгээ үзүүлж байна.

Дотоодын зах зээлд *жинхэнэ live auction*-ыг бодит цагаар, гар утсаар хүртээмжтэй, Монгол хэл-төгрөгийн орчинд эрхлэн явуулах систем нь өмнө бараг байгаагүй; иймд энэ ажил нь онол-практикийн талаас аль алинд хувь нэмэр оруулсан гэж үзэж байна.

## Төслийн үндсэн үр дүн

### Мобайл апликейшн

React Native болон Expo framework ашиглан хөгжүүлсэн cross-platform мобайл апликейшн нь:

* iOS болон Android төхөөрөмжүүд дээр ажилладаг.
* Веб апп-тай 100% функциональ тэгш.
* Google OAuth болон Firebase Phone Auth дэмждэг.
* Бодит цагийн дуудлага худалдаанд оролцох боломжтой.
* Монгол хэл дэмжлэгтэй.
* Хэрэглэгчдэд хаанаас ч, хэдийд ч дуудлага худалдаанд оролцох боломж олгосон.
* Push notification, watchlist, мэдэгдлийн төв, AI ангилал санал болгох гэх мэт хэрэглэгчийн туршлагыг өндөржүүлсэн.

### Веб апликейшн

React.js болон Vite ашиглан хөгжүүлсэн веб апликейшн нь:

* Хурдан, responsive дизайнтай.
* Админ хэрэглэгчдэд бүрэн удирдлагын систем.
* Rich text editor, AI категори санал болгох гэх мэт дэвшилтэт функцууд.
* Үнийн түүхийн график, шүүлтүүр, хайлтын систем.
* SEO-friendly URL, slug-аар бараа индексжүүлэгдэх боломжтой.

### Backend сервер

Node.js, Express.js, MongoDB ашиглан хөгжүүлсэн backend сервер нь:

* RESTful API архитектур, 34+ endpoint.
* Socket.IO ашиглан бодит цагийн мэдээлэл солилцох.
* JWT токен ашиглан аюулгүй нэвтрэлт, role-based authorization.
* Cloudinary-д зураг хадгалах CDN-аар хурдан хүргэх.
* MongoDB Atlas-д хадгалагдсан 11 collection.
* Unit, integration тестүүдийн 65%+ coverage.
* Cron job-аар auction lifecycle-ыг автоматжуулсан.

## Манай системийн давуу талууд

* **Multi-platform** — Веб, iOS, Android гурван платформ дээр ажилладаг.
* **Real-time систем** — Socket.IO ашиглаж үнийн өөрчлөлт, цагийн мэдээллийг цаг алдалгүй хүргэх.
* **Монгол зах зээлд тохирсон** — 66 төрлийн категори, төгрөг валют, Монгол хэл дэмжлэг.
* **AI технологи** — Категори автоматаар санал болгох систем.
* **Аюулгүй байдал** — JWT токен, bcrypt шифрлэлт, Firebase баталгаажуулалт, helmet, rate limiting.
* **Trust score систем** — Хэрэглэгчийн найдвартай байдлыг тоон утгаар хэмжих механизм.
* **Дотоодын баталгаажуулалт** — eMongolia integration plan, иргэний баталгаажуулалт.
* **Өргөн функционал** — Watchlist, мэдэгдлийн систем, үнийн түүх, шүүлтүүр гэх мэт.
* **Тест бүхий** — Unit test, Integration test, Mobile app testing.
* **Сүүлийн үеийн технологи** — React Native, Expo, Socket.IO, MongoDB гэх мэт орчин үеийн технологиуд.

## Хязгаарлалт

* **QPay merchant agreement** одоогоор sandbox. Бодит хэрэглээнд оруулахаас өмнө merchant бүртгэл, аюулгүй байдлын аудит хийх шаардлагатай.
* **Live video streaming** нэмж хэрэгжүүлэх ёстой.
* **Англи UI** 80% хөрвүүлэгдсэн; үлдсэн хэсгийг бүрэн дуусгах.
* **Multi-currency** дэмжлэг үгүй, төгрөг л байна.
* **Penetration test** мэргэжлийн талаас хийгдээгүй.

## Ирээдүйд хийж болох хөгжүүлэлтүүд

* **Live video streaming** — Худалдагч шууд дүрс ашиглаж дуудлага худалдааг явуулах (Shopee Live Auction шиг). WebRTC эсвэл Twilio Live Video ашиглах боломжтой.
* **Төлбөрийн систем** — QPay-ийг бодит орчинд нэвтрүүлэх, олон улсын төлбөрийн картууд (Stripe, PayPal), банкны шилжүүлэг шууд интеграц.
* **Блокчэйн технологи** — Блокчэйн суурьтай escrow, NFT дуудлага худалдаа, smart contract-аар автомат settlement.
* **AI чат бот** — Хэрэглэгчийн асуултад автомат хариулах OpenAI/Claude-д суурилсан bot.
* **Анти-снайпинг** — Сүүлийн секундэд орох санал бүрд auction-ы хугацааг 30 сек сунгах.
* **Push notification сайжруулалт** — Сегментлэгдсэн notification (watchlist, ангилал-based recommendations).
* **Social features** — Хэрэглэгч хоорондын мессеж, follow систем, public profile.
* **Analytics dashboard** — Худалдагчдад худалдааны статистик харуулах (impression, click-through, conversion rate).
* **Recommendation engine** — Collaborative filtering эсвэл content-based recommendation.
* **Multi-currency** — Бусад валют дэмжих, бодит цагийн ханш татаж конвертжуулах.
* **Multi-language** — Англи бүрэн, цаашид Хятад, Япон, Орос хэлийг нэмэх боломж.
* **Penetration testing** — Сторонняя ИБ багаас бичигдсэн pentest, OWASP ASVS соответствие.

## Төслийн ач холбогдол

Энэхүү онлайн дуудлага худалдааны систем нь Монгол улсын цахим худалдааны салбарт шинэ стандарт тогтоох боломжтой. Мобайл апликейшны хөгжүүлэлт нь хэрэглэгчдэд илүү хялбар, хүртээмжтэй үйлчилгээ үзүүлэх боломж олгож, цахим худалдааны өсөлтөд хувь нэмэр оруулж байна.

Мөн систем нь хуучин эд зүйлсийг дахин ашиглах, нөөцийг үр ашигтай ашиглах замаар байгаль орчинд ээлтэй шийдэл болж, нийгэм эдийн засагт эерэг нөлөө үзүүлж байна. C2C формат нь жижиг дунд бизнес эрхлэгчдэд барьцаагүй, түрээсийн зардалгүй борлуулалтын суваг олгож, цахим худалдааны нийт хүртээмжийг нэмэгдүүлж байна.

Технологийн талаас нь авч үзвэл, энэ ажил нь дотоодын инженерийн нийгэмлэгт *cross-platform + real-time + cloud-native* архитектурын бодит жишээ болж өгсөн. Backend дээр Node.js + MongoDB + Socket.IO, frontend дээр React.js + React Native, үүлэн сервист Cloudinary + Atlas + Firebase + Render-ыг хослуулсан стэк нь дотоодын стартапуудад загвар болж чадна.

Эцэст нь, энэ дипломын ажил нь онолоос практик руу шилжүүлэхэд — Vickrey-Myerson-ы аукшины теорийн revenue equivalence зарчмыг English auction хэлбэрээр практикт буулгаж, Akerlof-ийн мэдээллийн тэгш бус байдлыг trust score системээр шийдвэрлэх оролдлого зэрэг — эдийн засгийн онолын зарчмыг компьютерийн шинжлэх ухаантай хослуулан хэрэгжүүлсэн нэгэн жишээ болсон гэдэгт итгэлтэй байна.
