# Дипломын ажлын өргөтгөсөн ноорог (Markdown хувилбар)

Энэхүү хавтас нь одоо байгаа LaTeX дипломын (`archives/Bukhbilegt_DIPLOMA_MUSTlatest/Chapters/*.tex`)
өргөтгөсөн, нэмж тэлсэн ноорог хувилбар юм. Зорилго нь:

1. Одоогийн бүх агуулгыг хадгалах (танай LaTeX файл хэвээр үлдсэн).
2. Бүлэг бүрд нарийвчилсан тайлбар, шинжилгээ, эх сурвалжийг нэмэх.
3. Markdown хэлбэрээр уншиж, шалгаж, засаад дараа нь LaTeX-руу буцаан хөрвүүлэх.

## Файлуудын бүтэц

| Файл | Бүлэг | Тайлбар |
|------|-------|---------|
| `00_introduction.md` | Удиртгал | Сэдэв сонголт, зорилго, зорилт, шинэлэг тал |
| `01_theory.md` | Онолын хэсэг | Дуудлага худалдааны онол, технологи, ижил систем |
| `02_analysis_design.md` | Системийн шинжилгээ ба загварчлал | Шаардлага, архитектур, өгөгдлийн загвар |
| `03_implementation.md` | Системийн хөгжүүлэлт | Backend, Web, Mobile-н хэрэгжүүлэлт |
| `04_testing_results.md` | Туршилт, үр дүн | API, юнит, интеграц, мобайл тест |
| `05_conclusion.md` | Дүгнэлт | Үр дүн, ач холбогдол, ирээдүйн ажил |

## Дараагийн алхам

1. Энэ ноорогийг уншиж, агуулгад тохирох/таалагдсан хэсгийг тэмдэглэх.
2. Шаардлагатай засваруудыг хийх.
3. Эцсийн хувилбарыг `.tex` файлуудруу буцаан хөрвүүлэх.
