MAIN RELATIONSHIPS:

1. USER → PRODUCT (1:N)           - One user can sell many products
2. USER → BIDDING (1:N)           - One user can place many bids
3. USER → WATCHLIST (1:N)         - One user can watch many products
4. USER → REVIEW (1:N as writer)  - One user writes many reviews
5. USER → REVIEW (1:N as subject) - One user receives many reviews
6. USER → TRANSACTION (1:N buyer) - One user makes many purchases
7. USER → TRANSACTION (1:N seller)- One user makes many sales
8. USER → NOTIFICATION (1:N)      - One user has many notifications
9. USER → REPORT (1:N)            - One user files many reports

10. PRODUCT → BIDDING (1:N)       - One product has many bids
11. PRODUCT → WATCHLIST (1:N)     - One product watched by many
12. PRODUCT → REVIEW (1:N)        - One product has many reviews
13. PRODUCT → TRANSACTION (1:1)   - One product = one transaction
14. PRODUCT → NOTIFICATION (1:N)  - One product generates many notifications
15. PRODUCT → REPORT (1:N)        - One product has many reports

16. CATEGORY → PRODUCT (1:N)      - One category has many products
17. CATEGORY → CATEGORY (1:N)     - Parent-child hierarchy
